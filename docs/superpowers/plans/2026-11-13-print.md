# 列印（v1.0.38）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 程式內建的列印視窗：選印表機、份數、頁面範圍、紙張、方向、縮放、雙面、彩色／黑白、是否印註解、品質，版面有一般、多頁合一、手冊、海報；即時預覽每一面紙；依印表機記住設定；〔印表機內容…〕轉到系統列印對話框。

**Architecture:** 排版是純計算：`printPlan(st, doc)` 依設定算出每一面紙上放哪些頁、放在哪裡（點為單位）；`drawSide(plan, side, k, st)` 用 pdf.js（`intent:'print'`）把一面畫成畫布。預覽用螢幕解析度畫目前那一面；列印時每一面畫成 dpi/72 倍的 JPEG，放進只在列印時顯示的 `#printRoot`（`@page` 設成紙張大小、邊界 0），再由主程式 `webContents.print` 送出。主程式的印表機清單與送印有測試接口（`global.__pdfePrinters`、`global.__pdfePrintHook`）。

**Tech Stack:** Electron 45（`webContents.getPrintersAsync`、`webContents.print`、測試用 `printToPDF`）、pdf.js 4.10（`render({intent:'print', optionalContentConfigPromise})`）、`app/index.html`、`main.js`、`preload.js`、playwright-core e2e。

**Spec:** `docs/superpowers/specs/2026-11-13-print-design.md`

## Global Constraints

- 介面文字繁體中文（台灣）；commit 英文＋兩行 attribution；分支 `wip/print`；全部測試與最後檢查通過後直接發佈。
- 不改文件：列印不經過 `mutate()`，不產生復原步驟、不動 `S.bytes`。
- 紙張（點）：A4 595.28×841.89、A3 841.89×1190.55、A5 419.53×595.28、B4 728.50×1031.81、B5 515.91×728.50、Letter 612×792、Legal 612×1008。邊界：無 0、窄 5 mm、一般 10 mm。品質：一般 150 dpi、精細 300 dpi。
- 印表機清單第一項是「系統預設印表機」（`deviceName` 不給，Electron 的 PrinterInfo 沒有「預設」欄位）。
- 設定存在 `pdfeditor.print.v1`：`{last, by:{[printer]: {...}}}`（範圍、份數、奇偶、反向不存）。
- 文案：視窗標題「列印」；按鈕〔取消〕〔印表機內容…〕〔列印〕；「第 N／M 面」；「共 K 張紙」「× N 份」；「正在準備列印…（K／M）」；「已送到「印表機」」；「列印失敗：…」；範圍錯誤「頁面範圍的格式不對，例如：1-3, 5, 8-」。

## Review Focus

1. 頁面有 `/Rotate` 或是橫向的頁：預覽與印出方向正確，一般版面自動轉 90° 放進紙裡。→ Task 1 測試（fixture 第 5 頁橫向）。
2. 很大的文件（上百頁）：準備列印時可以取消，取消後 `#printRoot` 清空、不送印。→ Task 1 測試（取消）。
3. 自訂範圍的各種寫法（全形數字與逗號、空白、`8-`、`-3`、倒過來的 `5-3`、超出頁數）。→ Task 1 測試（`parseRange` 與紅字）。
4. 隱藏的圖層與標成不列印的註解不印、「只有文件」時註解與表單都不印。→ Task 1 測試（預覽像素）。
5. 換印表機或重開視窗時，設定帶入正確，範圍與份數不沿用。→ Task 1 測試。

- Test: `tests/e2e/print.mjs`（新檔，第 1 部分）

**Interfaces:**
- Produces:
  - 沿用現有的 `parseRange(txt, n): Set<number> | null`（減頁、插入 PDF、轉存圖片共用：逗號／頓號／空白分隔，`8-`、`-3`、`5-3`，超出頁數的略過，格式錯回 `null`），加上全形數字；列印用時依頁碼排序，結果是空的也算錯。
  - `printPages(st, n, cur, sel): number[]` — 範圍（`all|current|selected|custom`）→ 奇偶（`all|odd|even`，依頁碼）。
  - `printPlan(st): {paper:{w, h}, sides:[{items:[{i, x, y, w, h, rot, clip?}], blank?, label}], duplex}` — 一般版面：每頁一面，方向不同時轉 90°；縮放 `fit|shrink|actual|custom`；置中；反向列印把 `sides` 倒過來。
  - `drawSide(plan, side, k, st): Promise<HTMLCanvasElement>` — 白底，`k` 是每點幾個像素；黑白時轉灰階。
  - `openPrint()`、`runPrint(st, {dialog})`。
  - `__pdfapp.printState()` → `{open, sides, sheets, label, error}`（測試用）。
