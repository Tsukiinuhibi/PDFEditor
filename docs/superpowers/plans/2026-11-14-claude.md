# Claude 增益集（v1.0.43）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓使用者在 Claude 桌面版下指令，由 Claude 透過擴充功能（.mcpb）操作 PDF 工作台：讀文字、找與取代、加文字方塊／便利貼／螢光筆、頁面操作、復原、另存新檔。

**Architecture:** `claude.js`（主程式，可單獨測試）：本機 HTTP 橋（127.0.0.1、金鑰標頭、拒絕 Origin）、設定檔（`userData/claude.json`：enabled、key、port）。`main.js`：`claude:*` IPC，把呼叫轉給畫面（`claude:call` → `claude:result`）。`app/claude/server/index.js`（Claude 桌面版用自己的 Node 執行的 MCP 伺服器，stdio JSON-RPC，無相依套件）＋`app/claude/server/tools.json`（工具定義，伺服器與 manifest 共用）。`app/index.html`：設定的「Claude」頁、`.mcpb` 產生（`makeZip`）、工具實作 `CLAUDE_TOOLS`（都走 `mutate()`）。

**Tech Stack:** Electron 45、Node http、MCP（JSON-RPC 2.0 over stdio，protocolVersion 2025-06-18／2025-03-26／2024-11-05）、MCPB manifest 0.3、playwright-core e2e。

**Spec:** `docs/superpowers/specs/2026-11-14-claude-design.md`

## Global Constraints
- 介面文字繁體中文（台灣）；commit 英文＋兩行 attribution；分支 `wip/claude`；全部測試與最後檢查通過後直接發佈。
- 只接受 127.0.0.1；每個請求要有正確金鑰（`X-PDFE-Key`，timingSafeEqual）；有 `Origin` 標頭就拒絕；關閉時不接受。
- Claude 的修改一律 `mutate()`（可復原）；不覆蓋原檔；存檔只跳出另存新檔視窗。
- 位置單位：pt，頁面左上角為原點；頁碼從 1 開始。
- 打包清單 `build.files` 要有 `claude.js`；`npm run check` 檢查 `claude.js` 與 `app/claude/server/index.js`。

## Review Focus
1. 本機橋的安全：別的網頁（瀏覽器的 fetch 到 127.0.0.1）、沒有金鑰、金鑰錯、關閉後、重新產生金鑰後 → 一律拒絕（Task 1 測試）。
2. 呼叫時畫面上有開著的視窗（設定、列印…）或正在編輯文字方塊：工具要等或回報「PDF 工作台正在忙」，不能破壞正在進行的事（Task 2 測試：開著設定視窗時呼叫 `pdf_add_text` → 回報忙碌、文件不變）。
3. 沒有開啟文件時呼叫工具 → 清楚的訊息（Task 1 測試）。
4. 參數錯誤（頁碼超出、負的座標、空字串）→ 清楚的錯誤，文件不變（Task 2、3 測試）。
5. PDF 工作台沒開或沒打開允許 → MCP 伺服器回「連不上 PDF 工作台」的工具錯誤，不會讓 Claude 那邊卡住（Task 1 測試：關閉後呼叫）。
