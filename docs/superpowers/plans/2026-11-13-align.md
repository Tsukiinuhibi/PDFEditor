# 對齊功能（v1.0.36）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 「選取」工具可以多選物件（Shift＋點、拖曳選取框），選了 2 個以上時上方工具列可以對齊、平均分配、一起移動、一起刪除。

**Architecture:** 全部在 `app/index.html`。單選照舊（`AS`）；多選是新的 `MS = {i, items, els}`，畫外框、在 `#hint` 顯示多選列。把 `commitAnnotBox` 的移動／調整大小部分抽成 `moveAnnotInDoc(doc, i, id, ob, nb)`，多個物件的平移在一次 `mutate` 裡逐一呼叫它。

**Tech Stack:** Electron 45、`app/index.html`（`getAnns`、`selectAnnot`、`commitAnnotBox`、`mutate`、`snapAxis`）、playwright-core e2e。

**Spec:** `docs/superpowers/specs/2026-11-13-align-design.md`

## Global Constraints

- 介面文字繁體中文（台灣）；commit 英文＋專案規定的兩行 attribution；分支 `wip/align`，給使用者看預覽後才發佈。
- 每個動作一次 `mutate()`：「已對齊 N 個物件」「已平均分配 N 個物件」「已移動 N 個物件」「已刪除 N 個物件」；改完仍選著同一批。
- 只有能移動的物件能多選（不在 `NO_MOVE`、不是簽章欄位）；只在同一頁。
- 文案：「已選取 N 個物件」；〔靠左〕〔水平置中〕〔靠右〕〔靠上〕〔垂直置中〕〔靠下〕〔水平平均分配〕〔垂直平均分配〕；「對齊到」選單「選取範圍」「頁面」；〔刪除〕。

## Review Focus

1. 多選後切換工具、換分頁、翻到別頁：外框與工具列不殘留。→ Task 1 測試（換工具）。
2. 多選裡有隱藏或鎖定圖層的物件：選取框不會選到它（`getAnns` 已排除）。→ Task 1 測試。
3. 對齊時某個物件本來就在目標位置：不動、不出錯；全部都已對齊：仍是一個復原步驟或不產生步驟。→ Task 2 測試（最左那個不動）。
4. 旋轉過的戳記與一般矩形一起靠左：以轉後外框對齊，角度不變。→ Task 2 測試。
5. 線條、畫筆、文字方塊、便利貼一起移動：各自的點、彈出視窗跟著移動。→ Task 2 測試（線條＋文字方塊）。

### Task 1: 多選、一起移動、一起刪除

**Files:**
- Modify: `app/index.html`（新增 `MS`、`setMulti`、`toggleMulti`、`clearMulti`、`startMarquee`、`moveAnnotInDoc`（從 `commitAnnotBox` 抽出）、`moveObjects`、`deleteMulti`、多選工具列；`pagesEl` 的 pointerdown、物件的 pointerdown、鍵盤 Esc／Delete、`setTool`、`deselectAnnot`）
- Test: `tests/e2e/align.mjs`（新檔，第 1 部分）

**Interfaces:**
- Produces:
  - `MS: null | {i, items: Ann[], els: HTMLElement[]}`；`setMulti(i, items)`（2 個以上；1 個 → `selectAnnot`；0 → 清除）、`toggleMulti(i, a)`、`clearMulti()`。
  - `startMarquee(i, e, add)`：選取框，完全在框內、能移動的物件（`getAnns`）。
  - `moveAnnotInDoc(doc, i, id, ob, nb): boolean`（`commitAnnotBox` 改用它）。
  - `async moveObjects(i, moves: {a, ob, nb}[], label): Promise<boolean>`：一次 `mutate`，完成後 `setMulti` 同一批。
  - `async deleteMulti()`：一次 `mutate` 刪全部。
  - 多選時 `#hint` 加 `objbar multi`：`<b class="sb-t">已選取 N 個物件</b>` 與 Task 2 的按鈕位置；〔刪除〕`[data-ma="del"]`。
  - `__pdfapp.multi()`：`{i, ids}` 或 `null`。

### Task 2: 對齊與平均分配、文件

**Files:**
- Modify: `app/index.html`（新增 `alignSelected`、`distributeSelected`；多選列的按鈕與「對齊到」）、`HANDOFF.md`（一節、測試表）
- Test: `tests/e2e/align.mjs`（第 2 部分）

**Interfaces:**
- Consumes: Task 1 的 `MS`、`moveObjects`。
- Produces:
  - `async alignSelected(kind: 'left'|'hcenter'|'right'|'top'|'vcenter'|'bottom', to: 'sel'|'page')`：外框用 `getAnns` 的 `x, y, w, h`（旋轉過的是轉後外框）；不用動的物件不放進 `moves`；沒有要動的就不 `mutate`。
  - `async distributeSelected(axis: 'h'|'v')`：3 個以上；依中心排序，頭尾不動，相鄰空隙＝(總跨度 − 各寬度總和)／(N − 1)。
  - 按鈕 `[data-al="left|hcenter|right|top|vcenter|bottom"]`、`[data-dist="h|v"]`、`<select data-alto>`（`sel`／`page`，記在 `ALIGN_TO`）。
