# 物件的上下層級（v1.0.37）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每個物件都有上下順序：圖層面板依前後順序列出物件（預設展開），可以拖曳調整；選取的物件可以移到最上層／上移一層／下移一層／移到最下層。

**Architecture:** 全部在 `app/index.html`。順序就是每一頁 `/Annots` 的順序（後面的蓋在上面）。新增 `stackPlace(doc, i, id, how)` 在同一頁、同一個圖層裡重排 `/Annots`（便利貼的彈出視窗跟著走），最後 `restack(doc)`；`stackObj` 包成一次 `mutate` 並保留選取。換色重填與橡皮擦用 `keepPlace` 讓新物件回到原本的位置與圖層。

**Tech Stack:** Electron 45、`app/index.html`（`mutate`、`restack`、`readLayers`、`ocOfDict`、`layerable`、`buildLayersPanel`、`selectAnnot`）、playwright-core e2e。

**Spec:** `docs/superpowers/specs/2026-11-13-stacking-design.md`

## Global Constraints

- 介面文字繁體中文（台灣）；commit 英文＋專案規定的兩行 attribution；分支 `wip/stacking`；全部測試與最後檢查通過後直接發佈（使用者 2026-11-13 的規定）。
- 每個動作一次 `mutate()`：「已移到最上層」「已上移一層」「已下移一層」「已移到最下層」；面板拖曳「已調整前後順序」。改完仍選著同一個物件。
- 範圍：同一頁、同一個圖層（未分層的算一組）；「一層」＝面板清單的一格；便利貼的彈出視窗（`/Parent` 指向它）跟著它。
- 快速鍵用 `e.code`：Ctrl+Shift+BracketRight 移到最上層、Ctrl+BracketRight 上移一層、Ctrl+BracketLeft 下移一層、Ctrl+Shift+BracketLeft 移到最下層；加進 `RESERVED`。
- 提示：「已經在最上層」「已經在最下層」；物件在圖層裡且文件有 2 個以上圖層：「已經是「名稱」最上面的物件」「已經是「名稱」最下面的物件」；鎖定圖層：「這個圖層已鎖定，解鎖後才能調整」。

## Review Focus

1. 便利貼的彈出視窗不緊跟在便利貼後面（別的程式做的檔）：移動後彈出視窗仍跟著它，其他物件順序不亂。→ Task 1 測試（fixture 的彈出視窗放在別處）。
2. 頁面上有連結或表單欄位（不在圖層面板裡）：它們不算「一層」，位置不動。→ Task 1 測試（fixture 有一個 Link）。
3. 有圖層的文件：物件只在自己的圖層裡移動，`restack` 後圖層順序不變；鎖定圖層的物件在面板裡不能拖。→ Task 2 測試。
4. 在文字方塊裡打字時按 Ctrl+[ ／ Ctrl+]：不調整順序（`isTyping` 先擋）。→ Task 1 測試。
5. 換色重填、橡皮擦擦掉一部分：新物件回到原位與原本的圖層，不跑到最上面或目前圖層。→ Task 1 測試（橡皮擦）、Task 2 測試（重填在有圖層的文件）。

### Task 1: 上下層級的指令

**Files:**
- Modify: `app/index.html`（新增 `stackPlace`、`stackObj`、`keepPlace`、`STACK_LABEL`；選取小工具列 `.abar` 的四個按鈕與圖示 `zTop`、`zUp`、`zDown`、`zBot`；keydown 的快速鍵；`RESERVED`；`fillAt` 與 `eraseInk` 改用 `keepPlace`；測試 hook `annotsOrder`）
- Test: `tests/e2e/stacking.mjs`（新檔，第 1 部分）

**Interfaces:**
- Produces:
  - `stackPlace(doc, i, id, how): 'moved'|'same'|'top'|'bottom'|null`；`how` 是 `'front'|'forward'|'backward'|'back'` 或 `{rel:id2, above:boolean}`（放到 id2 的上面或下面，並換到 id2 的圖層；id2 在別頁 → `null`）。只動同一頁、同一個圖層的物件（`layerable` 的；彈出視窗跟著它的 `/Parent`）；其他項目（連結、表單欄位）相對位置不變；最後 `restack(doc)`。
  - `async stackObj(i, id, how, label?): Promise<boolean>`：鎖定圖層 → 提示、`false`；`top`/`bottom` → 提示、不產生復原步驟；成功後原本選著這個物件就重新選它、`buildLayersPanel()`。
  - `async keepPlace(doc, i, oldRef, fn)`：記下舊物件的位置與 `/OC`，執行 `fn()`（拿掉舊的、加新的），把新加的放回舊位置、套用舊的 `/OC`（沒有就拿掉）。
  - `.abar` 按鈕 `[data-x="z-front"|"z-up"|"z-down"|"z-back"]`（可以移動的物件才有）。
  - `__pdfapp.annotsOrder(i)`：`[{id, sub, parent}]`，`/Annots` 原樣順序。
