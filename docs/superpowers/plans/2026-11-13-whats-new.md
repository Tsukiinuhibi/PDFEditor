# 更新後顯示版本與更新內容（v1.0.29）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 更新後第一次開啟顯示「已更新到 vX.Y.Z」與更新內容；設定可隨時看版本記錄；下載好的新版在重新啟動前也看得到內容。

**Architecture:** 程式內建 `app/CHANGELOG.md`（已建好，v1.0.10–v1.0.28），渲染端以 `fetch('CHANGELOG.md')` 讀取、切成每版一段、轉成簡單 HTML。啟動時比對 localStorage 記錄的版本決定要不要跳視窗。`npm run check` 確保發佈時版本記錄、`RELEASE_NOTES.md` 與 `package.json` 一致。主程序把 Forgejo 發佈資料的 `body` 當成更新內容的備用。

**Tech Stack:** Electron 45、`app/index.html` 單檔渲染端（`openModal`、設定視窗）、`main.js`（electron-updater）、playwright-core e2e。

**Spec:** `docs/superpowers/specs/2026-11-13-whats-new-design.md`

## Global Constraints

- 介面文字繁體中文（台灣）；commit 英文＋專案規定的兩行 attribution；工作在 `wip/whatsnew`，預覽後才發佈。
- localStorage 鍵 `pdfeditor.seenversion.v1`（字串，版本號如 `1.0.28`）。
- 版本記錄每段標題格式 `## PDF 工作台 vX.Y.Z`，最新在最上面；Markdown 只轉 `##`／`###`、`- `、空行、`**粗體**`、`` `code` ``，其他先跳脫再照原文字顯示。
- 文案：視窗標題「已更新到 vX.Y.Z」；按鈕〔全部版本記錄〕〔知道了〕；設定按鈕〔更新內容〕；讀不到時「讀不到版本記錄」。
- 「用過」＝模組腳本一開始（任何寫入之前）localStorage 已有 `pdfeditor.` 開頭的鍵。

## Review Focus

1. **啟動時已經有別的對話框開著**（例如開啟的 PDF 要密碼）：不能蓋掉它，要等它關掉再顯示。→ Task 2 測試：設定視窗開著時呼叫顯示，關掉設定後才出現。
2. **版本記錄讀不到**（檔案缺失）：不跳視窗、不出錯；設定裡顯示「讀不到版本記錄」。→ Task 1 測試。
3. **裝回舊版**（記錄的版本比現在新）：不跳視窗，記下現在的版本。→ Task 2 測試。
4. **兩個版本之間沒有任何說明**（不該發生，但若發生）：不跳空視窗，照樣記下版本。→ Task 2 測試（`whatsNewList` 回空陣列）。
5. **說明裡有 HTML**：跳脫，不執行。→ Task 1 測試。

### Task 1: 讀取與呈現版本記錄、發佈檢查

**Files:**
- Modify: `app/index.html`（Desktop 段落之前新增「What's new」小段）、`scripts/check.mjs`
- Test: `tests/e2e/whats-new.mjs`（新檔，第 1 部分）

**Interfaces:**
- Produces:
  - `parseChangelog(text: string): {version: string, md: string}[]`：依 `/^## PDF 工作台 v(\d+\.\d+\.\d+)\s*$/m` 切段，`md` 不含標題行，順序同檔案。
  - `cmpVersion(a: string, b: string): number`：逐段數字比較。
  - `notesHTML(sections: {version, md}[]): string`：每段 `<h3 class="wn-v">vX.Y.Z</h3>` 加內容（`###` → `<h4>`、`- ` → `<ul><li>`、其他非空行 → `<p>`、`**x**` → `<b>`、`` `x` `` → `<code>`）。
  - `loadChangelog(url = 'CHANGELOG.md'): Promise<{version, md}[]>`：讀不到回 `[]`；預設網址的結果快取。
  - `__pdfapp.changelog(url?)`、`__pdfapp.notesHTML(md)` 測試用。
  - `scripts/check.mjs`：最上面一段的版本不等於 `package.json` 版本、或內容與 `RELEASE_NOTES.md` 不同時，印出原因並 exit 1。

### Task 2: 更新後第一次開啟的視窗

**Files:**
- Modify: `app/index.html`（模組腳本開頭記下 `PROFILE_USED`；Desktop 段落 `DESK.info()` 之後呼叫 `checkWhatsNew`）
- Test: `tests/e2e/whats-new.mjs`（第 2 部分：同一個使用者資料夾重開程式）

**Interfaces:**
- Consumes: Task 1 全部。
- Produces:
  - `whatsNewList({current, seen, used, versions}): string[]`（`versions` 由新到舊）：`seen` 比 `current` 舊 → `seen < v ≤ current` 的版本；沒有 `seen` 但 `used` → `≤ current` 的前兩個；其他 → `[]`。
  - `checkWhatsNew(current: string): Promise<void>`：先把 `current` 存進 `pdfeditor.seenversion.v1`，清單不空才呼叫 `showWhatsNew`。
  - `showWhatsNew(current: string, list: string[]): void`：`#mask` 開著就每 500 ms 再試；`openModal({title:'已更新到 v' + current, body:.wn 區塊, buttons:[〔全部版本記錄〕(換成全部版本、按鈕消失), spacer, 〔知道了〕]})`。
  - `__pdfapp.showWhatsNew`、`__pdfapp.whatsNewList` 測試用。
