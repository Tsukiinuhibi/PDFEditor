# 連結工具（v1.0.41）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用連結工具在頁面上拖曳一個框建立連結（網址、本文件的頁、電子郵件），看得到、能修改、刪除已有的連結；Ctrl＋點連結可以開啟。

**Architecture:** 全部在 `app/index.html`（主程式只放寬 `app:open-external` 到 http、https、mailto）。連結是標準的 `/Link` 註解：`/A <</S /URI /URI (…)>>` 或 `/Dest [頁 /Fit]`。`pageLinks(i)` 從 pdf.js 的 `getAnnotations` 取得連結（框、網址、目的頁）；連結工具時 `.lnk` 框畫在 `.ovl`。`openLinkDialog(i, {box}|{link})` 建立或修改，一次 `mutate`。

**Tech Stack:** `app/index.html`（`addAnnot`、`visToPdf`、`findAnnotRef`、`removeAnnotRefs`、`mutate`、`ensureOverlay`、`ACTION_MENUS`）、`main.js`、playwright-core e2e。

**Spec:** `docs/superpowers/specs/2026-11-13-link-design.md`

## Global Constraints

- 介面文字繁體中文（台灣）；commit 英文＋兩行 attribution；分支 `wip/link`；全部測試與最後檢查通過後直接發佈。
- 每個動作一次 `mutate()`：「已建立連結」「已修改連結」「已刪除連結」。
- 工具名 `link`；「插入」分段按鈕 `ACTION_MENUS.insert`：〔插入圖片…〕〔連結〕。
- 網址沒有 `scheme:` 就補 `https://`；只開 http、https、mailto。
- 文案：視窗「建立連結」／「修改連結」；「連到」：網址／本文件的頁面／電子郵件；「外觀」：不顯示框／細藍框；〔取消〕〔刪除連結〕〔建立〕／〔儲存〕；提示「開啟網址：…」「跳到第 N 頁」「寄信給：…」。

## Review Focus

1. 頁面有 `/Rotate`：拖曳的框和建立的連結位置一致（`visToPdf`）。→ Task 1 測試（第 2 頁旋轉 90°）。
2. 頁碼超出範圍、空的網址：〔建立〕停用、紅字。→ Task 1 測試。
3. 其他程式做的連結（命名目的地、JavaScript 動作）：顯示得出來、點了不會出錯；修改時換成我們的格式。→ Task 2 測試（fixture 的命名目的地）。
4. 刪除連結後復原：連結回來，框也回來。→ Task 2 測試。
5. 選取工具下點到連結的位置：照常選取物件，不會被連結擋住；只有 Ctrl＋點才開啟。→ Task 2 測試。
