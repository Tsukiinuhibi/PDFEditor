# 從網頁開啟 PDF（v1.0.40）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 貼上網址或把瀏覽器裡的 PDF 連結拖進來，就下載並在新分頁打開。

**Architecture:** 主程式 `url:fetch(id, url)` 用 `net.fetch`（Chromium 網路：轉址、Proxy、憑證）下載到記憶體，邊下載邊送 `url:progress`，`url:cancel(id)` 中止；檢查 `%PDF`、取檔名（`Content-Disposition` 的 `filename*`／`filename`，否則網址最後一段）。頁面的 `openUrlDialog(url?, {auto})` 是一個小視窗（網址、進度、取消），成功後 `openInNewTab(bytes, name, null)`。

**Tech Stack:** Electron 45（`net.fetch`、`clipboard`）、`main.js`、`preload.js`、`app/index.html`、playwright-core e2e（測試裡的本機 HTTP 伺服器）。

**Spec:** `docs/superpowers/specs/2026-11-13-url-design.md`

## Global Constraints

- 介面文字繁體中文（台灣）；commit 英文＋兩行 attribution；分支 `wip/url`；全部測試與最後檢查通過後直接發佈。
- 只接受 `http:`、`https:`；上限 500 MB；60 秒沒有資料就停。
- 文案：視窗「從網址開啟」、「PDF 的網址」、〔取消〕〔開啟〕；「網址要以 http:// 或 https:// 開頭」；「下載中…（N MB）」；「這個網址下載到的不是 PDF 檔（可能需要登入，或是一個網頁）」；「下載失敗（404）」；「檔案太大（超過 500 MB）」；「太久沒有收到資料，已停止下載」；「無法連線：…」。
- 快速鍵 Ctrl+Shift+O（加進 `RESERVED`）。

## Review Focus

1. 下載中關掉視窗（Esc、點遮罩）：下載也要停，不會之後突然開出分頁。→ Task 1 測試。
2. 檔名：`filename*=UTF-8''…` 的中文、`filename="…"`、網址裡的 `%E5…`、沒有副檔名、含 `/\:*?` 的字。→ Task 1 測試（中文檔名、沒有副檔名）。
3. 伺服器回 HTML 但網址結尾是 .pdf；回 PDF 但沒有 Content-Length。→ Task 1 測試。
4. 很慢的伺服器：進度更新、取消立刻生效。→ Task 1 測試。
5. 拖進來的是網頁連結（不是 PDF）：提示，不開分頁。→ Task 2 測試。

```js
// 本機伺服器：/files/a.pdf（範例 PDF，有 Content-Length）、/r → 302 → /dl（filename*=UTF-8''報告.pdf，chunked、沒有 Content-Length）、
// /noext（PDF，網址沒有副檔名）、/page.pdf（其實是 HTML）、/missing（404）、/slow.pdf（先送 1 KB 再停 30 秒）
```
