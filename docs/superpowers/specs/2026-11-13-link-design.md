# 連結工具（v1.0.41）設計

日期：2026-11-13　狀態：使用者說「不用先問我，有問題可以先以你的判斷先做」，以下都是我的決定

## 目的
使用者：「之後再新增連結工具的功能／有不知道的再詢問我」。在 PDF 上建立連結。

## 做法
- 採用：標準的 PDF 連結註解（`/Subtype /Link`），其他閱讀器（Acrobat、瀏覽器）都能點。目標可以是網址（`/A /URI`）、本文件的某一頁（`/Dest [頁 /Fit]`，跳到那一頁、整頁可見），或寄信（`mailto:`）。
- 不採用：把連結畫成看得到的按鈕或文字（那是文字方塊或圖形的事，連結本身是透明的區域）。

## 設計
1. **連結工具**（照 HANDOFF 放進現有按鈕：「註解」群組的〔插入圖片〕改成分段按鈕「插入」：〔插入圖片…〕〔連結〕）：在頁面上拖曳一個框（通常框住要點的那幾個字），放開後跳出「建立連結」視窗。
2. **建立連結視窗**：
   - 連到：網址／本文件的頁面／電子郵件。
   - 網址：輸入框（沒有 http:// 就自動補 https://）；頁面：頁碼（1～N）；郵件：地址。
   - 外觀：不顯示框（預設）／細藍框。細藍框除了 `/Border`、`/C`，也畫成連結的外觀（`/AP`），本程式和 Edge、Chrome 才看得到；跟 Acrobat 一樣只在螢幕上顯示，列印時不印（不設列印旗標）。修改連結時外觀沒改就不動原本的外觀。
   - 〔取消〕〔建立〕。一次 `mutate`，「已建立連結」。
3. **看得到連結**：用連結工具時，頁面上所有連結都標出淡藍色框；滑鼠移上去顯示目標（「開啟網址：…」「跳到第 N 頁」）。
4. **修改與刪除**：連結工具時點一下已有的連結 → 同一個視窗，帶入目前的目標，多一個〔刪除連結〕；改完一次 `mutate`。
5. **點連結**：任何工具下 Ctrl＋點連結：網址用預設瀏覽器開（http、https、mailto）；頁面就跳過去。連結工具下單點就是修改（不跳）。
6. 復原、圖層：連結不放進圖層（PDF 的連結沒有選擇性內容），照現有規則（`LAYER_SKIP`）。

## 不做（這版）
- 連到其他 PDF 檔、執行 JavaScript、命名目的地的管理。
- 文字自動變連結（偵測網址）。

## 測試（新檔 `tests/e2e/links.mjs`）
- 連結工具拖曳框 → 視窗 → 網址 example.com → 建立：頁面上有一個 Link，`/A /URI` 是 https://example.com、沒有框線；一個復原步驟。
- 頁面連結：連到第 2 頁 → `/Dest` 指向第 2 頁；Ctrl＋點 → 目前頁變成第 2 頁。
- 郵件：`mailto:` 網址。
- 連結工具下：已有的連結有淡藍框；點一下 → 視窗帶入目標，改成另一個網址 → 改好；〔刪除連結〕→ 不見；復原回來。
- Ctrl＋點網址連結 → 主程式收到開啟 https://example.com（測試裡攔下來）。
- 外觀選細藍框 → `/Border` 有寬度、`/C` 是藍色、有 `/AP`、沒有列印旗標；頁面上看得到藍框。
