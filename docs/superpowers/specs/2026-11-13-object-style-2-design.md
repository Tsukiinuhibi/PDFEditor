# 選到物件時工具列：文字方塊、戳記、圖片、區塊填色（v1.0.34）設計

日期：2026-11-13　狀態：使用者說「開始」；細節先前說「你自行判斷」，以下是我的決定

## 目的
接續 v1.0.33：用選取工具選到「文字方塊、戳記、圖片、點選區塊的填色」時，上方提示列也換成它的編輯功能，改了就套用到這個物件。
v1.0.33 的設計已寫明這一版做：「文字方塊（字型、字級、顏色套用到整個方塊）、戳記、圖片、『點選區塊』的填色（圖片式）」。

## 共同規則（同 v1.0.33）
- 提示列標題「已選取：<名稱>」，下面是這種物件的設定，值是這個物件目前的。
- 一次修改＝一個復原步驟；改完仍選著它；只改這個物件，工具的預設（`TB_STYLE`、`STAMP_SEL`、`STYLES`）不變。
- 旋轉過的戳記、圖片、填色：改完維持原角度。頁面在物件畫好之後才旋轉的（物件跟著頁面側躺）：改完維持它原本的方向與大小。
- 取消選取、換工具：提示列收起或換回工具自己的。

## 1. 文字方塊（`FreeText`，有 `PDFE` 與 `PDFE_RT`；主旨「文字方塊」或「修改的文字」）
- 提示列：和文字方塊工具同一組——字型、字級、顏色、文字底色、粗體／斜體／底線、方塊背景、框線；提示「套用到整個方塊・雙擊可修改文字」。
- 顯示的值：第一段文字的字型、字級、顏色、底色；粗體／斜體／底線要「每一段都是」才顯示為開；方塊背景、框線照方塊。字級不在清單裡（例如 13）就把它加進清單。
- 套用：改哪一項就把「每一段文字」的那一項改掉，其他項不動（原本大小不一的字，改顏色後大小仍不一）；粗體／斜體／底線是切換：全部都有→全部拿掉，否則全部加上（以套用當下的內容判斷，連按兩下也正確）。
- 重新排版：用和編輯完成時同一套方式重畫（`renderTextBox`），方塊左上角不動，大小跟著內容；文字內容不變。
- 字型選單：同文字方塊工具的選單，選了就套用到整個方塊。

## 2. 戳記（`Stamp`，主旨「戳記」）
- 從這版起，蓋戳記時把戳記的設定（文字、顏色、樣式、姓名、蓋章時間）存在物件裡（`PDFE_Stamp`），並加上 `PDFE` 標記。
- 提示列：〔更換戳記…〕、顏色、透明度。
- 〔更換戳記…〕：開啟「選擇戳記」視窗（預選這個戳記），選好就換掉它：中心不動、維持目前的縮放比例（舊版蓋的戳記：和原本一樣高）；角度、透明度保留；時間是現在，作者是目前的使用者。不改戳記工具目前選的戳記。
- 顏色：同一個戳記換顏色重畫，日期與姓名維持原本的，大小、位置不變。
- 舊版蓋的戳記（沒有存設定）：可以〔更換戳記…〕和調整透明度，沒有顏色（提示「舊版蓋的戳記無法改顏色，可以更換戳記」）。

## 3. 圖片（`Stamp`，主旨「圖片」，有 `PDFE`）
- 提示列：〔更換圖片…〕、透明度。
- 〔更換圖片…〕：選一個圖檔，新圖放進原本的框裡（照新圖的長寬比、置中，不變形）；角度、透明度保留；名稱換成新檔名。

## 4. 點選區塊的填色（`Stamp`，名稱 `Fill`，主旨「填色」）
- 提示列：同 v1.0.33 的填色（預設樣式、顏色、透明度）。
- 換顏色：同一塊區域換顏色（形狀不重新偵測）；只換顏色時保留原本的透明度。
- 透明度：整塊換成新的透明度。
- 從這版起，填色時透明度不是 100% 也記在物件上（`CA`），提示列才顯示得出來。

## 透明度（戳記、圖片）
- 選項同其他物件：100%、85%、70%、50%、35%。
- 寫法：物件上記 `CA`；外觀包一層有透明度的外觀，再改時換掉這一層（不會一層層疊上去），改回 100% 就拿掉這層。

## 不做（這版）
- 文字方塊只改其中幾個字（請用雙擊進入編輯）。
- 戳記改姓名或日期（請用〔更換戳記…〕的自訂戳記）。
- 頁面本身的圖片（「擷取圖片」，排在之後）。

## 測試（新檔 `tests/e2e/object-style-2.mjs`；`object-style.mjs` 裡「文字方塊沒有樣式列」那一項改成有）
- 文字方塊：選到→提示列「已選取：文字方塊」、字級是它的；改字級→每段都變、方塊變大、左上角不動、內容不變；改顏色、粗體（再按一次取消）、方塊背景、框線、字型；大小不一的兩段改顏色→大小仍不一；復原一次回到上一步；工具預設不變。
- 戳記：新蓋的有設定；改顏色→設定的顏色變、大小與時間不變；透明度 50%→70%→100%（外觀只包一層，100% 時沒有）；〔更換戳記…〕換成另一個→中心不動、工具預設不變；旋轉過的改顏色→角度不變；舊版戳記→沒有顏色、有〔更換戳記…〕。
- 圖片：〔更換圖片…〕→名稱換了、在原框內置中不變形；先設 50% 再換圖→仍是 50%。
- 區塊填色：選到→提示列「已選取：填色」；換顏色→畫面上那塊變成新顏色；透明度 50%→畫面變淡、物件記 50%。
