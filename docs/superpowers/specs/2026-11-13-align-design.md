# 對齊功能（v1.0.36）設計

日期：2026-11-13　狀態：使用者說「先照你的判斷做」，以下都是我的決定

## 目的
使用者：「還希望增加對齊功能，物件跟物件之間可以對齊，也能選擇要靠左靠右或置中」；「我的物件是指所有能拆開編輯移動的所有物件」。

## 範圍
- **這版**：用工具加上去、能用「選取」拖曳的物件（文字方塊、圖形、線條、箭頭、多邊形、畫筆、戳記、插入的圖片、便利貼、填色、簽名圖…）。
- **不算**：高亮／底線／刪除線（跟著文字）、表單欄位、連結（本來就不能移動）；PDF 原本的文字和圖片（現在不能移動，要另外做成可移動，之後再談）。

## 做法
- 採用：多選＋上方工具列（`#hint`）的對齊鈕。對齊、分配、一起移動都是把每個物件平移，用調整大小時同一套移動方法（`commitAnnotBox` 的移動部分），一次修改＝一個復原步驟。
- 不採用：只做「對齊到頁面」的單選功能——使用者要的是物件之間對齊。

## 設計
1. **多選**（只在同一頁）
   - 「選取」工具 Shift＋點物件：加入選取；再 Shift＋點一次：移出。
   - 在空白處拖曳：畫出選取框，完全在框內的物件都選起來（按住 Shift 是加入原本的選取）。框到 1 個就是一般的單選。
   - 點空白處或按 Esc：取消選取。
   - 每個選到的物件有外框；沒有個別的把手與小工具列。
2. **上方工具列**（選了 2 個以上）：「已選取 N 個物件」、〔靠左〕〔水平置中〕〔靠右〕〔靠上〕〔垂直置中〕〔靠下〕、3 個以上才有〔水平平均分配〕〔垂直平均分配〕、「對齊到：選取範圍／頁面」、〔刪除〕。
3. **對齊**：以每個物件在畫面上的外框（旋轉過的用轉後的外框）為準。對齊到「選取範圍」＝所有選到物件的整體外框；「頁面」＝頁面四邊與中心。
4. **平均分配**：依位置排序，最前與最後不動，中間的讓相鄰物件之間的空隙相等。
5. **一起移動**：拖曳其中一個，全部跟著移動（不吸附參考線，只移動外框；拖曳中按 Esc 回到原位）。
6. **刪除**：Delete／Backspace 或〔刪除〕一次刪掉全部選到的。
7. 改完仍選著同一批物件；每個動作一個復原步驟：「已對齊 N 個物件」「已平均分配 N 個物件」「已移動 N 個物件」「已刪除 N 個物件」。

## 不做（這版）
- PDF 原本的文字與圖片的對齊。
- 跨頁多選、Ctrl＋A 全選、方向鍵微調。

## 測試（新檔 `tests/e2e/align.mjs`）
- 拖曳選取框選 3 個矩形 →「已選取 3 個物件」；Shift＋點移出一個 → 2 個；Esc → 取消。
- 靠左 → 三個 x 相同（最左那個不動）；復原一次回到原位；水平置中、靠下、對齊到頁面（水平置中 → 中心＝頁面中心）。
- 平均分配（水平）→ 中間那個的左右空隙相等。
- 旋轉過的物件以轉後外框對齊。
- 拖曳其中一個 → 全部平移同樣距離；Delete → 全部刪除、復原回來。
- 線條、文字方塊、戳記一起對齊也正確（各種物件的移動方式）。
