# 選到物件時工具列換成它的編輯功能（v1.0.33）設計

日期：2026-11-13　狀態：使用者已同意範圍（「開始」）；先前就這一點說「你自行判斷」，細節是我的決定

## 目的
使用者：「選取什麼物件工具列就自動更換成那個選取物的編輯功能」（「右鍵預設功能更變」的第三點）。
現在工具列上的顏色、粗細只影響「之後新畫的」；這版讓「已經畫好的」物件也能直接改。

## 範圍（已同意）
- **這版（圖形類，本程式畫的）**：矩形、橢圓、雲狀、線條、箭頭、多邊形、多邊形線條、畫筆、高亮文字、底線文字、刪除線文字、以節點／矩形／套索畫的填色（多邊形）、區域螢光筆（新畫的）。
- **v1.0.34**：文字方塊（字型、字級、顏色套用到整個方塊）、戳記、圖片、「點選區塊」的填色（圖片式）。
- **其他軟體畫的物件**（沒有本程式的標記 `PDFE`）：這版只能移動、刪除，不顯示樣式列。

## 做法
- **採用**：選到支援的物件時，上方提示列（`#hint`）顯示「畫這種物件時」的同一組設定（`styleBar`），但值是這個物件的，改了就套用到它：寫回物件的樣式欄位（`C`、`IC`、`BS`、`CA`、`LE`），再用畫它時同一套幾何重新產生外觀（和調整大小時重畫的方式相同），一次修改＝一個復原步驟，改完仍選著它。
- 不採用：在物件旁的小工具列（`.abar`）加按鈕——位置窄、和使用者說的「工具列」不同。

## 設計
1. **哪些物件、哪組設定**：Square（無雲狀）→ 矩形；Circle → 橢圓；有 `BE` 的 → 雲狀；Line 有箭頭 → 箭頭，否則線條；Polygon（主旨「填色」）→ 填色（顏色、透明度）；其他 Polygon → 多邊形；PolyLine → 多邊形線條；Ink → 畫筆；Highlight／Underline／StrikeOut → 高亮／底線／刪除線文字。
2. **提示列**：標題「已選取：<名稱>」＋該工具的設定（預設樣式、框線顏色、填色、粗細、虛線、透明度、箭頭樣式；填色只有顏色與透明度），顯示這個物件目前的值；沒有〔完成 (Esc)〕。取消選取或換工具就收起。
3. **套用**：
   - 顏色、填色（含「無填色」）、粗細、虛線、透明度、箭頭樣式、預設樣式（一次套用它的各項）。
   - 只改這個物件，不改工具的預設（`STYLES` 不變）。
   - 旋轉過的矩形／橢圓／雲狀：重畫後維持原角度。
   - 封閉箭頭的箭頭填色跟著線條顏色。
4. **區域螢光筆**：新畫的加上 `PDFE` 標記與主旨，之後就能改顏色、透明度（舊的維持只能移動、刪除）。
5. **不支援的物件**（文字方塊、戳記、圖片、點選區塊的填色、便利貼、簽章欄位、其他軟體的物件）：照舊，沒有樣式列。

## 不做（這版）
- 一次選多個物件一起改。
- 〔設為預設〕把物件的樣式存成工具的預設。

## 測試（新檔 `tests/e2e/object-style.mjs`）
- 矩形：選到後提示列顯示它的顏色與粗細；改粗細、框線顏色、填色、無填色、虛線、透明度 → 物件的樣式跟著變，仍選著它；復原一次回到上一個樣式；工具預設不變。
- 箭頭：改成封閉箭頭；線條：改粗細。多邊形、畫筆：改顏色。高亮文字：改顏色。節點填色：改顏色。
- 預設樣式：點一個預設 → 物件換成那組樣式。
- 旋轉過的矩形改顏色 → 角度不變。
- 其他軟體的物件（沒有 `PDFE`）、文字方塊：沒有樣式列。
