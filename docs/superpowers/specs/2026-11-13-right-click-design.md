# 右鍵回到選取（v1.0.31）設計

日期：2026-11-13　狀態：使用者交給我判斷（「你自行判斷」），以下的取捨都是我的決定

## 目的
使用者：「在空白處點擊右鍵不要再出現如圖的選單；且要在是插入／新增物件文字（包含選取框那類的都要）後，用右鍵點擊文件空白處會自動切回選取功能；選取什麼物件工具列就自動更換成那個選取物的編輯功能」。

## 做法
- **分兩版**（採用）：v1.0.31 做右鍵（前兩點，小改動）；v1.0.32 做「選到物件，工具列換成它的編輯功能」（每種物件都要能改已經畫好的樣式，工作量大）。使用者的原則「簡單的先提前做」。
- 不採用：一版做完三點，右鍵的改動要等很久才拿得到。

## 設計（v1.0.31）
1. **文件上按右鍵（頁面或頁面之間的灰色處）不再跳頁面選單。** 頁面選單只在左側縮圖按右鍵出現（功能不變）。
2. **在空白處按右鍵 → 回到選取工具**，任何工具都一樣（文字方塊、便利貼、圖形、線條、畫筆、橡皮擦、填色、戳記、高亮、擷取圖片、文字辨識、簽名、插入圖片、手形）。已經是選取工具時，取消目前的選取。
   - 切換時照「完成 (Esc)」的規則收尾：畫筆筆跡存好、文字方塊的文字存好、擷取圖片的框取消、文字辨識的結果視窗關閉。
   - **正在畫的多邊形／多邊形線條、填色的節點**：按右鍵等於畫完（點數夠就建立，不夠就放棄，不跳錯誤訊息），再回到選取。
3. **在物件上按右鍵**：回到選取，並選到那個物件（和左鍵點選一樣出現選取框）。便利貼照 v1.0.30 跳出〔編輯〕〔複製〕〔刪除〕選單；數位簽章欄位只回到選取。
4. **不變的**：打開的便利貼視窗、正在編輯的文字方塊（它自己的文字格式選單）、文字辨識結果視窗、色彩滴管裡按右鍵，維持原本的行為。
5. **提示文字**：文字方塊工具不再寫「左鍵或右鍵」在十字處輸入；各工具的〔完成 (Esc)〕滑鼠提示加上「或在空白處按右鍵」。

## 不做（v1.0.31）
- 選到物件時工具列換成它的編輯功能（v1.0.32）。
- 其他物件的右鍵選單。

## 測試（新檔 `tests/e2e/right-click.mjs`）
- 選取工具：右鍵空白處 → 沒有選單、仍是選取、原本的選取被取消。
- 每種工具（文字方塊、便利貼、矩形、畫筆、高亮、擷取圖片、文字辨識、手形…）右鍵空白處 → 選取工具、沒有選單。
- 文字方塊工具：右鍵不會新增文字方塊；畫筆畫一筆後右鍵 → 筆跡存好。
- 多邊形點了 3 點後右鍵 → 建立多邊形；只點 1 點就右鍵 → 不建立、沒有錯誤訊息。
- 畫筆工具下右鍵矩形 → 選取工具，矩形被選到。
- 右鍵便利貼 → 仍是便利貼選單；縮圖右鍵 → 仍是頁面選單；頁面之間的灰色處右鍵 → 選取工具。
