# 尋找與取代（v1.0.39）設計

日期：2026-11-13　狀態：使用者說「不用先問我，有問題可以先以你的判斷先做」，以下細節都是我的決定；需求來自 HANDOFF 待辦（使用者先前的答覆）

## 目的
HANDOFF 待辦：Ctrl+F 尋找列，全部符合處標示、顯示「第 N／M 筆」、Enter／Shift+Enter 上下筆；左側加「搜尋」分頁列出頁碼與前後文；選項：區分大小寫、全字相符、全形半形視為相同。使用者要「也搜尋掃描頁」：沒有文字的頁先用文字辨識讀一次（記住結果），掃描頁只能找、不能取代。取代：逐筆或全部取代，用修改原文的機制，取代後是真正的文字、可復原；字型沿用修改原文選字型的能力。

## 做法
- 採用：每一頁的文字依「修改原文」同一套方式分成行（`pageTextItems` → `lineOf` → `joinRow`，行與行之間不跨行比對），在行的文字裡找；符合處依字在行裡的位置算出框，畫在頁面上。取代時把那一行（或本程式寫的文字區塊）照「修改原文」的方式重寫：拿掉原本的字、用同樣的字型寫回取代後的整行，所以是真正的文字、一次復原。
- 不採用：只換掉符合的那幾個字、其他字不動（PDF 的字是一段一段畫的，字型子集常常沒有新的字，硬換容易變成亂碼）；跨行比對（取代時兩行要一起重寫，排版容易跑掉）。
- 掃描頁（整頁沒有文字）：勾選「也搜尋掃描頁」時才用文字辨識讀，讀過的頁記住（文件沒改就不用再讀），符合處標「辨識」，不能取代。

## 設計
1. **尋找列**（Ctrl+F，頁面區右上角浮動）：輸入框、「第 N／M 筆」、〔▲〕〔▼〕、選項〔Aa 區分大小寫〕〔全字相符〕〔全形＝半形〕（預設開）、「也搜尋掃描頁」、〔取代 ▸〕展開取代列、〔×〕。Enter 下一筆、Shift+Enter 上一筆、F3／Shift+F3 也可以；Esc 關閉並清掉標示。打字後 250 ms 自動搜尋。
2. **標示**：全部符合處淡黃色框，目前這筆橘色框並捲到看得到；換頁、縮放、修改後重新畫。
3. **「搜尋」分頁**（左側面板，在「圖層」旁）：依頁列出每一筆的前後文（符合的字加粗），點一下跳到那一筆；掃描頁的標「辨識」。
4. **掃描頁**：勾選後，沒有文字的頁在背景逐頁辨識（「辨識掃描頁…（K／M）」，可以取消；關掉尋找列就停），辨識結果依文件版本記住。
5. **取代**（取代列：「取代為」輸入框、〔取代〕〔全部取代〕）
   - 〔取代〕：取代目前這筆，然後跳到下一筆。
   - 〔全部取代〕：所有能取代的一次取代，一個復原步驟「已取代 N 處」；掃描頁的不取代，提示「掃描頁的 M 處沒有取代」。
   - 原本的文字：整行照修改原文重寫（字型找得到、可以嵌入就用原本的，否則思源黑體並提示）；本程式寫的文字區塊：改區塊裡的文字後整塊重寫，保留各段格式。
   - 取代成空字串＝刪除那些字。
6. 選項與「也搜尋掃描頁」記在 `pdfeditor.find.v1`。

## 不做（這版）
- 跨行比對、正規表示式。
- 註解（文字方塊、便利貼）裡的文字。
- 轉向（非 0／90／180／270 度）的文字。

## 測試（新檔 `tests/e2e/find.mjs`）
- 兩頁有文字（含大小寫、全形英數、整字與部分字）＋一頁是圖片（掃描頁，上面有字）：Ctrl+F 輸入 → 「第 1／N 筆」、標示數量；Enter／Shift+Enter 換筆並捲動；區分大小寫、全字相符、全形＝半形各改變筆數。
- 「搜尋」分頁列出每一筆（頁碼、前後文），點一下跳過去。
- 也搜尋掃描頁：掃描頁的字被找到、標「辨識」；〔取代〕在那一筆上提示不能取代。
- 〔取代〕一筆：那一行的文字變了（`pageTextItems` 讀得到新字）、其他行不變；一次復原回來。
- 〔全部取代〕：全部變了、一個復原步驟、提示筆數；取代成空字串會刪掉。
- 本程式寫的文字區塊裡的字也能取代，區塊的格式（粗體、顏色）保留。
- Esc 關閉、標示清掉；Ctrl+F 在文字方塊編輯中不搶。
