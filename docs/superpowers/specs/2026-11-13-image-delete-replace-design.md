# 擷取圖片：點選圖片後可刪除或更換（v1.0.35）設計

日期：2026-11-13　狀態：做法與更換視窗的樣子使用者已同意（「可以」）；細節是我的決定，下面標示

## 目的
使用者要處理 PDF 裡「一般的圖片」（照片、插圖，不是 logo）：用「擷取圖片」工具點選頁面上的圖片後，除了擷取，還能**從檔案裡刪除**這張圖片，或**換成另一張圖**。
同一張圖出現在多處時，「只處理這一張」和「全部一起處理」兩種都要有，用的時候再選（使用者：「可以都做再來選擇要用哪個」）。

## 現在的樣子
- 「擷取圖片」工具：pdf.js 讀出頁面畫的圖片，標成紅框（`detectImages`）；點紅框 → 選取框＋小工具列〔確定擷取 (Enter)〕〔取消〕→ 裁切後下載。
- 這些圖片在頁面內容（content stream）裡，用 `/名稱 Do` 畫出圖片物件（Image XObject）；少數是內嵌圖片（`BI … ID … EI`）；也可能包在表單物件（Form XObject）裡。同一個圖片物件可以被畫在很多地方。
- 程式已有修改頁面內容的工具：`csTokens`（帶位元組位置的運算子）、`pageContentBytes`、`removePageText` 的寫回方式。

## 做法（Approaches）
1. **採用：直接改頁面內容。** 刪除＝把畫那張圖的指令拿掉；更換＝改成畫新的圖片物件。用不到的圖片資料一併從檔案移除。舊圖真的不在了，搜尋、列印、其他閱讀器都一致。
2. 不採用：在圖上蓋白框、把新圖疊上去（註解或另加內容）。簡單，但舊圖的資料還在檔案裡，不符合「從檔案刪除」，用工具還拿得出來。
3. 不採用（只當內部手段）：直接替換圖片物件的資料。會同時改到所有用到它的地方，無法「只換這一張」；也無法保持比例。

## 設計
1. **小工具列**：選取框是點紅框選到的圖片時，變成〔確定擷取 (Enter)〕〔刪除圖片〕〔更換圖片…〕〔取消〕。自己拖曳框選的範圍沒有後兩個鈕。拖曳把手改了範圍也一樣作用在整張圖片（按鈕寫的是「圖片」）。〔我的決定〕
2. **刪除圖片**
   - 這張圖只畫在這裡：直接刪除（可復原），提示「已刪除圖片」。
   - 同一個圖片物件還畫在別處（同一頁或其他頁，包括共用內容被畫在多頁的情形）：先問「這張圖片在文件裡出現 N 次」〔取消〕〔只刪這一張〕〔全部 N 處都刪〕。
   - 圖片幾乎佔滿整頁（例如掃描頁，面積 ≥ 頁面的 90%）：先確認「刪除後這頁會變成空白」。〔我的決定〕
   - 刪除後，沒有任何地方再用到的圖片資料（含它的透明遮罩）從檔案移除，另存的 PDF 裡就沒有它。
3. **更換圖片…**
   - 先選圖檔（格式同「插入圖片」：PNG、JPG、WebP、GIF、BMP、SVG）。
   - 再跳出「更換圖片」視窗：新圖預覽；放法 (•) 保持比例，放在原本範圍的中間　( ) 填滿原本的範圍（可能變形）；範圍 (•) 只有這一張　( ) 全部 N 處（圖片出現在多處時才有這一行）；〔取消〕〔更換〕。預設放法「保持比例」〔我的決定，同 v1.0.34 的更換圖片〕。
   - 新圖畫在舊圖原本的位置與方向（旋轉、翻轉跟著舊圖）。舊圖用不到了就從檔案移除。提示「已更換圖片」或「已更換 N 處圖片」。
4. **只有這一張**：只影響點選的那一處。圖片在被畫在多頁的共用內容裡時，先複製一份共用內容給這一處再改，其他頁不變。
5. **復原**：每次刪除／更換是一個復原步驟。
6. **找不到可以修改的指令**（例如畫在字型裡的圖）：提示「這張圖片無法刪除或更換」，不做任何修改。

## 不做（這版）
- 左側「圖片」分頁的清單也加刪除／更換（之後可加）。
- 註解、戳記、本程式插入的圖片（那些用「選取」工具處理，v1.0.34 已有〔更換圖片…〕）。
- 刪除框選範圍內的一部分圖片（只處理整張）。

## 測試（新檔 `tests/e2e/image-edit.mjs`，用 pdf-lib 產生測試 PDF）
- 單一圖片：點紅框 → 有〔刪除圖片〕〔更換圖片…〕；刪除 → 紅框消失、畫面該處變白、存出的檔案裡沒有那個圖片物件；復原 → 回來。
- 同一張圖在兩頁：刪除 → 詢問；〔只刪這一張〕→ 另一頁還在、圖片資料還在；〔全部 2 處都刪〕→ 兩頁都沒有、資料移除。
- 更換：寬圖換成高圖，保持比例 → 在原範圍內置中、不變形；填滿 → 範圍相同；全部 N 處 → 每處都換、舊圖資料移除。
- 旋轉／翻轉畫的圖片：換了之後方向跟著舊圖。
- 內嵌圖片（`BI … EI`）可以刪除、更換。
- 共用內容被畫在兩頁：只換這一張 → 另一頁不變。
- 佔滿整頁的圖片：刪除前先確認。
- 自己拖曳框選的範圍：沒有刪除／更換鈕。
