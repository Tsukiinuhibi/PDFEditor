# 物件的上下層級（v1.0.37）設計

日期：2026-11-13　狀態：使用者說「不用先問我，有問題可以先以你的判斷先做」，以下都是我的決定

## 目的
使用者：「所有做出來的物件都要有上下層級的關係並顯示在圖層裡面」。

## 現況
- 每一頁的物件依 `/Annots` 的順序畫：後面的蓋在前面的上面（pdf.js 依序畫在畫布上；點選用的感應區也依同樣順序疊，點到的是最上面那個）。
- 有圖層的文件：`restack` 讓 `/Annots` 依圖層排序（未分層在最下面，上面的圖層畫在後面），同一個圖層裡維持原本的先後。
- 新物件加在 `/Annots` 最後（最上面）；有圖層時是該圖層的最上面。
- 圖層面板：每個圖層可以展開看物件（預設收合），順序是第 1 頁先、同一頁裡最下面的先，每列標「P1」。
- 會把物件拿掉再加回去的修改：填色工具在原本的填色上再點一次（換色重填）、橡皮擦擦掉畫筆的一部分。這兩個會讓物件跑到最上面。

## 做法
- 採用：順序直接用每一頁 `/Annots` 的順序（PDF 本來就這樣畫，其他閱讀器看到的也一樣）；圖層面板顯示並調整它，選取物件旁的小工具列和快速鍵也能調。
- 不採用：另外記一個「層級編號」（其他閱讀器看不懂，存檔後會跟畫出來的順序不一致）；把每個物件做成自己的圖層（圖層是 PDF 的選擇性內容群組，數量一多其他閱讀器的圖層清單會很亂）。

## 設計
1. **面板的順序就是上下層級**：每個圖層展開後，依頁分段（「第 N 頁」小標題），同一頁裡**最上面的物件排第一個**（跟繪圖軟體的圖層清單一樣）。不再在每列標「P1」。
2. **物件清單預設展開**：圖層一打開就看得到物件；按 ▸ 可以收合（記住收合的，不記住展開的）。
3. **在面板裡拖曳物件調整順序**：
   - 拖到同一頁的另一個物件上：放在它的上面（滑鼠在那列的上半）或下面（下半）；如果那個物件在別的圖層，順便換到那個圖層。
   - 拖到圖層列上：換到那個圖層，放在那個圖層該頁的最上面。
   - 拖到別頁的物件上：不能放（不顯示放置線）。
   - 鎖定圖層裡的物件不能拖，也不能放進鎖定的圖層（提示「這個圖層已鎖定」）。
4. **四個指令**：〔移到最上層〕〔上移一層〕〔下移一層〕〔移到最下層〕
   - 選取物件旁的小工具列（`.abar`）：四個小圖示按鈕，滑鼠停留顯示名稱與快速鍵。
   - 圖層面板物件的右鍵選單。
   - 快速鍵（與 Office、Illustrator 相同）：Ctrl+Shift+] 移到最上層、Ctrl+] 上移一層、Ctrl+[ 下移一層、Ctrl+Shift+[ 移到最下層；加入「按鍵設定」不能被佔用的清單。
   - 範圍：同一頁、同一個圖層裡（圖層的順序優先；要蓋過上面圖層的物件，要先換到那個圖層）。「一層」＝面板清單裡的一格。
   - 已經在最上面（或最下面）：不產生復原步驟，提示「已經在最上層」／「已經在最下層」；在圖層裡時提示「已經是「圖層名」最上面的物件」。
   - 便利貼的彈出視窗跟著便利貼一起移動。
   - 改完仍選著同一個物件；復原步驟：「已移到最上層」「已上移一層」「已下移一層」「已移到最下層」；面板拖曳：「已調整前後順序」。
5. **面板標出選到的物件**：在頁面上選取物件時，面板裡那一列反白（多選時每個都反白）。
6. **修改不改變順序**：換色重填、橡皮擦擦掉一部分後，新的物件放回原本的位置，不會跑到最上面。

## 不做（這版）
- PDF 原本的文字與圖片（頁面內容）永遠在最底層，不能調到物件上面。
- 多選時的上下層級指令（一次只調一個物件；面板一次拖一個）。
- 跨頁移動物件。

## 測試（新檔 `tests/e2e/stacking.mjs`）
- 同一頁畫兩個重疊、顏色不同的填滿矩形：重疊處是後畫的顏色；選前面那個〔移到最下層〕→ 重疊處變成另一個的顏色；一次復原 → 回來。
- 面板：展開的清單裡後畫的排第一個；〔移到最上層〕後順序對調。
- 快速鍵 Ctrl+] / Ctrl+[ / Ctrl+Shift+] / Ctrl+Shift+[ 各移一次，順序符合預期；已在最上層再按 → 提示、沒有新的復原步驟。
- 面板拖曳：把最下面的物件拖到最上面那列的上半 → 變成最上面；拖到別頁的物件上 → 沒有變化。
- 有兩個圖層：下層圖層的物件〔移到最上層〕→ 仍在上層圖層的物件下面（提示是該圖層最上面）；拖到上層圖層的物件上 → 換到那個圖層並蓋在它上面。
- 便利貼移到最下層 → 它的彈出視窗仍在它後面一格（`/Parent` 指向它）。
- 選取物件 → 面板那一列反白；換色重填與橡皮擦後順序不變。
