# 修正：從其他 PDF 插入頁面（v1.0.44）設計

日期：2026-11-14　狀態：使用者說「那個插入可以不用測試」（不用等他的檔案）。以下都是我的決定。

## 問題
使用者回報（2026-11-12，附截圖）：插入「承攬商施工前必備檢核資料.pdf」時，視窗顯示「共 1 頁」，預覽是一張全白的 Letter 大小頁面；一般 PDF 正常。使用者沒有提供檔案。

## 原因（用自己做的檔案重現）
1. **PDF 包**（Portfolio：目錄有 `/Collection`，真正的文件是內嵌檔案）：pdf.js 只讀得到外層的封面頁。封面頁如果是空白 Letter，畫面就跟截圖一模一樣。
2. **XFA 動態表單**（`/NeedsRendering true`，AcroForm 有 `/XFA`）：只讀得到預留頁。
3. **不需要密碼就能開、但有權限密碼（「限制編輯」）的加密 PDF**：預覽正常，但插入後的頁面是白的（AES）或亂掉（RC4）。原因是 pdf-lib 不會解密，複製過來的串流仍是加密的。
4. 同樣的加密檔**直接開啟**：可以看，但每一個修改都失敗，顯示「操作失敗：No password given」。原因是 pdf-lib 另存後，加密的驗證對不上，pdf.js 打不開。另外，失敗的修改仍會留下一個復原步驟，分頁也被標成有修改。

## 做法
- **`pdfcrypt.js`（主程式，可單獨測試）**：`decryptPdf(bytes)` 用空白的開啟密碼解密，回傳下列其中一種：
  - `{state:'plain'}`
  - `{state:'decrypted', bytes, signed}`
  - `{state:'password'}`：需要開啟密碼
  - `{state:'unsupported', reason}`

  支援範圍：
  - 標準加密處理程式：V1/V2/V4/V5、R2–R6，包含 RC4 40/128 位元、AES-128、AES-256。
  - 物件串流（ObjStm）、`EncryptMetadata false`、Identity 加密篩選、`/EFF`。
  - 簽章的 `/Contents` 不解密（規格規定它沒有加密）。

  規則跟 pdf.js 一樣：只試空白的開啟密碼，金鑰長度的規則相同，AES 補位的寬鬆處理也相同。用 Node 的 crypto 做 MD5、SHA-2、AES；RC4 自己寫。主程式提供 IPC `pdf:decrypt`，preload 提供 `decryptPdf`。
- **開啟**（`openInNewTab`，涵蓋開檔、從網址開啟、Claude 的 `pdf_open`）：
  - 解密成功：用解密後的內容開啟，並提示「這份 PDF 有「限制編輯」的保護：PDF 工作台已解除，修改後另存的新檔不會再有這個保護」。
  - 有數位簽章的加密檔不解密（避免開啟時就悄悄讓簽章失效），維持原狀。
  - 需要密碼或不支援：跟現在一樣。
- **修改失敗**（`mutate`）：不留下復原步驟、不標成有修改。文件仍是加密的而 pdf.js 打不開結果時，提示「這份 PDF 有加密保護，PDF 工作台無法修改它」。
- **插入視窗**（`insertFromPdf`）：
  - 來源先解密。
  - 來源有內嵌的 PDF（PDF 包或一般附件）時，也列出它們的頁面：一個檔案一段，有標題（檔名、頁碼範圍）。頁碼接續編號，跟「頁碼範圍」輸入框一致。
  - 預設勾選：PDF 包勾選內嵌 PDF 的頁面；其他 PDF 勾選本身的頁面。
  - 說明列寫出不是 PDF 的附件、讀不到的附件（需要密碼或損壞）。
  - XFA 動態表單：黃色警告說明原因，並教轉成一般 PDF（Adobe Reader →「列印」→「Microsoft Print to PDF」），預設不勾選。
  - 插入時依頁碼順序（勾選框的編號由小到大），從各自的來源複製頁面。
- **附件分頁**：PDF 附件多一個〔開啟〕（在新分頁開啟）。開啟 PDF 包時提示「這是 PDF 包：裡面的檔案在左側「附件」分頁」。

## 不採用
- 把 XFA 表單畫成一般頁面：pdf.js 的 XFA 版面不完整，結果不可靠。
- 對需要開啟密碼的檔案詢問密碼：使用者沒有要求，維持現狀。
- 遵守權限旗標（P）禁止修改：程式本來就能看、能印這些檔案；修改失敗是錯誤，不是設計。發佈說明會寫清楚。

## 測試
- `tests/e2e/pdf-decrypt.mjs`：只用 Node，用固定的測試檔驗證每一種加密，以及解密後的字串與串流。
- `tests/e2e/encrypted-open.mjs`：開啟、修改、復原、另存（新檔沒有加密、原檔沒變）；需要密碼的檔案；修改失敗不留復原步驟。
- `tests/e2e/insert-pdf.mjs`：一般 PDF、PDF 包（封面 + 2 個 PDF + 1 個文字檔）、XFA、加密來源、內嵌加密 PDF、附件〔開啟〕。

測試檔：`tests/e2e/fixtures/encrypted/*.pdf`，由 `make.py`（pikepdf / qpdf）產生並一起提交。
