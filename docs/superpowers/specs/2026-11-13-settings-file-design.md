# 匯出／匯入設定檔（v1.0.32）設計

日期：2026-11-13　狀態：使用者沒有異議（「有不知道的再詢問我」），以下照上一則訊息提出的做法；細節是我的決定

## 目的
使用者：「再做可以匯出及匯入整個程式的設定檔」。用途（我的推測）：換電腦、重灌，或讓同事用同一套設定（人員名單、繪圖樣式、按鍵）。
依使用者「簡單的先提前做」，排在「選到物件時工具列換成它的編輯功能」（改為 v1.0.33）之前。

## 做法
- **採用**：設定視窗多一個「設定檔」頁，〔匯出設定…〕存成一個 `.json` 檔，〔匯入設定…〕讀回來後重新載入程式。程式的設定都在 localStorage（`pdfeditor.` 開頭的鍵），原樣存進檔案、原樣寫回。
- 不採用：只匯出部分設定、或匯入時逐項勾選——使用者要「整個程式的設定」。

## 設計
1. **設定 → 設定檔**（分頁放在「人員」後面）：說明一句、〔匯出設定…〕〔匯入設定…〕。
2. **匯出**：檔名預設「PDF工作台-設定-YYYYMMDD.json」，用另存新檔對話框選位置。內容：
   `{"app":"PDF 工作台","kind":"settings","version":"<程式版本>","exported":"<ISO 時間>","settings":{"pdfeditor.theme":"…", …}}`
   - 包含：所有 `pdfeditor.` 開頭的鍵（外觀、頁面色彩、工具列、按鍵、人員名單、繪圖工具樣式、顏色我的最愛、戳記、文字方塊樣式、檢視輔助、轉存圖片設定、最近用過的字型與工具…），以後新增的設定也自動包含。
   - 不包含：`pdfeditor.fontcat.v2`（這台電腦的字型清單快取）、`pdfeditor.seenversion.v1`（看過哪一版的更新內容）。
   - 完成後提示「已匯出設定：<檔名>」。
3. **匯入**：選一個 `.json` 檔。
   - 不是這個程式的設定檔（讀不到、不是 JSON、`app`／`kind` 不對、`settings` 不是物件、裡面沒有可用的設定）→ 錯誤提示「這不是 PDF 工作台的設定檔」，什麼都不改。
   - 只接受 `pdfeditor.` 開頭、不在「不包含」名單、值是文字的項目；其他忽略。
   - 確認視窗：「匯入設定」，內容列出檔名、匯出時的版本與日期、會取代幾項設定，並說明「匯入後程式會重新載入；有還沒另存的修改會先提醒你」。〔取消〕〔匯入並重新載入〕。
   - 確定：檔案裡有的設定寫入（取代），檔案裡沒有的維持原樣；然後重新載入程式（原本的「尚未儲存」保護照常）。
4. **瀏覽器版**（非桌面版）：匯出改用瀏覽器下載；匯入相同。

## 不做
- 匯入時逐項勾選、合併兩份設定。
- 匯出手寫簽名、開過的檔案清單（不在設定裡）。

## 測試（新檔 `tests/e2e/settings-file.mjs`）
- 匯出：改了幾項設定（暗色、人員名單、畫筆顏色）後匯出（另存對話框由測試接管）→ 檔案的 `app`／`kind`／`version` 正確，含這幾項，不含字型快取與版本記錄。
- 匯入：設定改回別的值後匯入剛才的檔案 → 重新載入後三項都回來；檔案裡沒有的鍵維持原樣。
- 不是設定檔（一般 JSON、壞掉的檔案）→ 錯誤提示，設定沒變。
- 取消確認 → 設定沒變、沒有重新載入。
