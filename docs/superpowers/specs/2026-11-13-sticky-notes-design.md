# 便利貼功能增強（v1.0.30）設計

日期：2026-11-13　狀態：使用者已同意（做法「可以」、設計「可以」）

## 目的
使用者：「便利貼新增刪除的功能選項／右鍵點擊已經放置的便利貼可以編輯/複製/刪除／也可以編輯新增人員的名字／檔案設定中可以設定預設人員名字的名單／這個名單可以新增/刪除」。
用途：便利貼留給交接、修改檔案的人看。便利貼上的名字代表**這張是誰寫的**（作者，PDF 的 `/T`），交接時接手的人把預設名字換成自己。

## 做法（已同意）
- **改作者：點便利貼標題上的名字，跳出名單**（採用）。不採用：右鍵選單的「作者 ▸」，要先知道右鍵才找得到。
- **複製：放進程式的剪貼簿，Ctrl+V 貼在滑鼠所在的位置**（採用），文字同時放進系統剪貼簿。不採用：按「複製」立刻在旁邊多一張，只能留在同一頁。

## 設計
1. **人員名單**（設定 → 新分頁「人員」）
   - 每列：〔◉ 預設〕名字〔🗑〕；下方輸入框＋〔新增〕（Enter 也可以）。名字去頭尾空白；空白、重複的不加（重複時提示「名單裡已經有…」）。
   - 預設的名字是之後**所有新註解**的作者（便利貼、文字方塊、螢光筆、戳記…，即程式裡的 `AUTHOR`）。
   - 至少留一個名字：只剩一個時〔🗑〕不能按。刪掉預設的名字時，第一個名字變成預設。
   - 第一次：名單是電腦的帳號名稱（沒有時「使用者」），它是預設。
   - 存在 localStorage `pdfeditor.people.v1`：`{names:[…], def:'…'}`。
2. **便利貼視窗**
   - 標題的名字變成按鈕「王小明 ▾」：點了跳出名單（目前作者打勾），下面「其他名字…」可以直接輸入（Enter 確定）。輸入的新名字自動加進名單。
   - 換作者跟改文字一樣，關掉便利貼時一起存，一次復原就回到原本的作者；還沒存的新便利貼，建立時就用選的名字。
   - 作者不在名單裡（例如別人用 Acrobat 寫的）：照樣顯示在最上面打勾，不會被加進名單。
   - 刪除鈕改大、改明顯（垃圾桶圖示，滑過變紅，提示「刪除這張便利貼」）。新的便利貼也有：按了就不要這張，什麼都不存。
3. **右鍵點已經放好的便利貼**（任何工具下都可以；點在便利貼圖示上）
   - 選單標題「便利貼 · 作者」，下面〔編輯〕〔複製〕〔刪除〕。
   - 〔編輯〕打開這張便利貼；〔刪除〕刪掉（可復原）；〔複製〕見下一點。
   - 右鍵點在打開的便利貼視窗裡：不跳任何選單（現在會跳頁面選單）。
4. **複製、貼上**
   - 〔複製〕記下這張的文字、作者、視窗大小；文字同時放進系統剪貼簿。提示「已複製便利貼，按 Ctrl+V 貼到滑鼠所在的位置」。
   - 用選取工具選到便利貼（拖動過它）時，Ctrl+C 也是複製這張。
   - Ctrl+V 貼上**最後複製的東西**：最後複製的是便利貼就貼便利貼，是頁面就照舊貼頁面。工具列的〔貼上頁〕只貼頁面。
   - 貼在滑鼠所在的頁面與位置；滑鼠不在頁面上時，貼在目前這頁、原本的位置往右下偏一點。也可以貼到另一個開著的檔案。
   - 貼上的便利貼保留原本的作者（「誰寫的」不變），時間是現在；一次貼上＝一個復原步驟。
   - 下方狀態列的剪貼簿顯示最後複製的東西（「📋 剪貼簿：便利貼「…」」）。

## 不做
- 不做便利貼的回覆、狀態、顏色。
- 不改空白處的右鍵選單（下一項「右鍵預設功能更變」再做）。

## 測試（新檔 `tests/e2e/sticky-notes.mjs`）
- 人員名單：初始是電腦帳號；新增兩個、改預設、刪除一個；重複與空白不加；只剩一個時不能刪；重開程式（同一個使用者資料夾）名單還在。
- 預設名字：新便利貼、新的螢光筆註解的作者都是預設名字。
- 便利貼的名字 ▾：列出名單；換人後存檔的作者改變，復原一次就回來；「其他名字…」輸入後作者改變、名單多一個。
- 右鍵：選取工具與其他工具（例如畫筆）下，右鍵點便利貼都出現〔編輯〕〔複製〕〔刪除〕；編輯打開、刪除刪掉（復原回來）。
- 複製＋Ctrl+V：滑鼠在第 2 頁時貼在第 2 頁滑鼠位置，文字、作者相同；系統剪貼簿是便利貼的文字；之後複製頁面，Ctrl+V 又變回貼頁面。
- 刪除鈕：新便利貼按了不會產生註解；存好的便利貼按了被刪除。
